# septalamaison
Sept à la Maison est un calendrier mensuel interactif conçu pour sublimer vos liens d'affiliation. Inspirée par l'esthétique épurée de Pinterest, sa grille affiche chaque jour une idée déco, jardin, cuisine ou bien-être. Retrouvez des objets détourés sur fond crème et des citations inspirantes, tous cliquables vers vos coups de cœur.
